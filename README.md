# GCBPCR

**GCBPCR** is the concise repository name for **Geometry-Constrained Bidirectional Point Cloud Registration**.

The full paper title is:

> Geometry-Constrained Bidirectional Point Cloud Registration for Thin, Sheet-Like Heritage Artifacts

This lightweight repository provides a stable, short entry point to the official resources:

- [Project page](https://zyz-nwpu.github.io/Geometry-Constrained-Bidirectional-Point-Cloud-Registration/)
- [Source code](https://github.com/zyz-nwpu/Geometry-Constrained-Bidirectional-Point-Cloud-Registration)

The acronym is limited to the core method name; the full title is retained wherever the publication is identified or cited.
